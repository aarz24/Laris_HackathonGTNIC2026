The root is a single Next.js 15 (Turbopack) application whose `src/` tree provides the authenticated app shell (`src/app/page.tsx`, `src/components/laris-app.tsx`) and API routes under `src/app/api/ai/` for Gemini-powered order parsing, OCR, and Tanya Laris. All persistent data lives in Supabase; schema, RLS policies, and atomic RPCs are versioned in `supabase/migrations/` and must be applied in strict numeric order. Tenant isolation is enforced at the database layer via `business_id` columns plus RLS, with server-side membership checks in RPCs — client code never trusts the browser for authorization. The shared domain model and deterministic fallback parser live in `src/lib/laris-data.ts`, while `src/lib/repo.ts` maps Supabase snapshots per active workspace. Dev/ops tooling is centralized in `scripts/` (seed, RLS integration test, CSS polish, voice benchmark) and invoked through npm scripts that use Node 22's native TypeScript stripping (`--experimental-strip-types`) plus `.env` loading. A `/demo` route provides an explicit local-only mode with fake Kopi Senja data that never masquerades as cloud.
