Requires Node.js 22.18+; after `npm install`, run `npm run dev` to start the Turbopack dev server. Cloud setup requires copying `.env.example` to `.env`, setting Supabase URL/publishable key, `NEXT_PUBLIC_APP_URL`, and optionally `SUPABASE_SERVICE_ROLE_KEY`; then apply migrations in order `0001_schema.sql → 0002_rls.sql → 0003_functions.sql → 0004_workspaces.sql → 0005_production_hardening.sql`. Verification: `npx tsc --noEmit && npm run lint && npm test && npm run eval:voice && npm run build`. Seed demo tenants with `npm run db:seed`, run RLS isolation tests with `npm run test:rls`, and evaluate the Indonesian voice parser against `evals/voice.jsonl` with `npm run eval:voice`.
